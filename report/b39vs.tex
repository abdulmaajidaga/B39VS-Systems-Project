\section{Introduction}

\subsection{Project overview}

The project involves the design and development of an autonomous mobile manipulator capable of picking up waste from waste points and disposing of it at the base station. 

The robot, designated ‘Hazmat’ manufactured by SLAM Industries, is equipped with a Raspberry Pi 5 as its main processor, assisted by an ESP32-S3 to offload computational tasks. This configuration reduces the processing burden on the Pi and provides an additional safeguard against potential hardware faults due to faulty wiring. 

Hazmat is fitted with mecanum wheels, enabling omni-directional movement and allowing it to smoothly traverse through tight spaces within a factory environment. The robot utilizes a stereo-depth camera (Oak-D Pro W) with an integrated IMU, motor encoders, and a 2D LiDAR (Rplidar A3) to perform simultaneous localization and mapping (SLAM), enabling it to autonomously locate waste containers and navigate to disposal points. 

Hazmat is also equipped with a 3-DOF manipulator designed using a four-bar linkage mechanism, and a dual-claw soft servo gripper for efficient waste pickup and placement. The servo motors were modified to output potentiometer feedback to the Pi, enabling real-time inverse kinematics calculations for the robotic arm. Power is supplied by a lithium polymer battery that drives the wheels, while a buck converter is used to step down voltage for the robot’s electronic systems. 

\subsection{Aims and objectives}

Aims:

\begin{itemize}

    \item To design, fabricate, and demonstrate a functional, autonomous mobile manipulator capable of navigating an indoor environment, picking up hazardous waste containers, and delivering them to designated disposal areas with minimal human intervention. 

\end{itemize}

Objectives:

\begin{itemize}

\item Design and fabricate a stable mobile robot based on mecanum wheels to allow omnidirectional movement in constrained indoor environments. 


\item Develop a secure container compartment to safely transport waste containers during robot motion. 


\item Integrate vision and ranging sensors (stereo camera, 2D LiDAR, ultrasonic sensors) to enable environmental perception, obstacle detection, and navigation. 


\item Design and build a 3-DOF robotic manipulator with a four-bar linkage for grasping and moving waste containers. 


\item Implement autonomous navigation using SLAM (Simultaneous Localization and Mapping) and obstacle avoidance algorithms. 


\item Implement object and container recognition using colour coding and computer vision methods. 


\item Develop audio feedback features to alert humans during path obstruction scenarios. 


\item Integrate micro-ROS middleware to allow reliable communication between the embedded control systems and the central processor. 


\item Implement a user interface and visual indicators (LEDs or screen) to display robot status and task progress. 


\item Develop a simple autonomous charging strategy (proposal stage) for future continuous operation.


\item Simulate and test robot behaviour in Gazebo or a relevant simulation environment before real-world testing. 


\item Manage team roles and collaborate effectively across mechanical, electrical, and software domains to achieve system integration.

\end{itemize}

\subsection{Project scope}

This project focused on the design, development, and demonstration of a scaled-down autonomous mobile manipulator intended for hazardous waste handling in an industrial indoor environment. The system combines mechanical design, embedded electronics, and advanced software integration to meet the key operational requirements. 

The main elements covered within the project scope included:

\begin{itemize}
\item Designed a stable mobile base with mecanum wheels for omnidirectional movement in confined spaces. 
    

\item Assembled a 3-DOF manipulator with a four-bar linkage for waste handling. 
    

\item Integrated a secure containment compartment to safely transport waste containers. 
    

\item Integrated a stereo depth camera and 2D LiDAR for environment perception and mapping. 
    

\item Implemented basic colour detection for container identification. 
    

\item Developed SLAM-based autonomous navigation between pickup and drop-off points. 
    

\item Implemented basic path planning with fallback behaviour for obstacle avoidance. 
    

\item Added an audio feedback system to alert humans blocking the path. 
    

\item Fully integrated mechanical, electrical, and software subsystems. 
    

\item Used micro-ROS for communication between the Raspberry Pi and ESP32 controllers. 
    

\item Implemented initial robot status communication via ROS topics. 
    

\item Created a simulation environment for validating inverse kinematics, PID control, and navigation algorithms. 
    

\item Conducted multiple rounds of physical testing for calibration and optimization. 
    

\item Structured task division across team members specializing in mechanics, electronics, software, and marketing. 
    

\item Regular design reviews and troubleshooting sessions to address integration challenges.
\end{itemize}
